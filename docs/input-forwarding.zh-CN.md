# 真实输入转发

Remote DOM 的本地页面是远程网页的受限镜像，不能透明转发浏览器的全部状态。输入通道尽量保留用户已经做出的操作，不生成额外轨迹、随机延迟或自动操作。

## 实时操作

- 普通页面元素的鼠标、触摸和笔输入分别发送按下、移动、松开。远端不再等到本地 click 才补发一次瞬时点击，也不再等拖动超过阈值才补发按下。
- 首次按下通过节点和节点内相对坐标定位，包含内嵌页面偏移；后续位置沿用同一坐标映射。页面缩放计入换算。
- 鼠标与笔移动最多每 16 ms 发送一个实际采样点，松开前发送最后一个待发点。网络发送受阻时，只合并相邻、尚未发出的移动位置；按下和松开不会被合并。不插值，不随机生成位置。笔输入携带浏览器提供的压力与倾角。
- 按键分别发送 keydown/keyup，重复 keydown 保留为重复按键；Ctrl、Meta、Alt、Shift 分别处理。
- 本地后续生成的兼容 click 不会再次激活远端。键盘触发的 click 和专用控件仍走各自处理路径。

## 取消与恢复

失焦、隐藏页面、pointercancel、切换远程窗口和导航会清理相关按住状态。WebSocket 断开时，服务器按连接归属释放输入，本地也清除正在进行的操作。重连不重放未完成的按住或点击。

触摸使用原生 touchCancel。鼠标/笔在视口外释放，避免取消时激活原来按住的按钮。HTTP 断网或未收到释放时还有 30 秒无输入超时保护；长时间保持静止的按住也会触发该保护。

## 保留的转换和限制

- 普通触屏滚动由本地浏览器完成，再同步滚动位置。浏览器开始滚动而发出 pointercancel 时取消远端触摸，避免本地和远端重复滚动。`touch-action:none` 的拖动区域支持转发触摸移动。
- 单次只转发一个触点；第二个触点会取消当前操作，多指缩放尚未支持。远端设备未启用触摸时，触摸操作降级为鼠标操作。
- 文本编辑、中文输入法、原生选择器、媒体控件和复制按钮继续使用已有专用通道，尚非完整的按键或指针透传。
- 仅主按钮走实时指针通道；右键/中键及完整本地系统菜单尚未实现。
- 网络延迟、队列和浏览器调度会改变实际到达间隔，不能保证时序逐毫秒一致；没有把客户端时间戳伪装成服务器事件时间。

这些改动提升交互准确性，不改变代理、Cookie 或浏览器身份，也不保证第三方验证通过。

## 验证

`tests/e2e/live-input.test.ts` 使用真实 Chromium，通过 HTTP 与 WebSocket 分别验证鼠标/触摸按下在松开之前到达、按住时长、单次激活、取消、断线恢复、重复按键、独立修饰键、笔压力/倾角和触摸拖动。已有滚动、双击、缩放拖拽、跨域内嵌页面、中文编辑、复制、弹窗与上传下载测试用于检查兼容性。
