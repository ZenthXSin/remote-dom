# 采集链路的样式字典

复杂页面每次采集都会包含数千份计算样式。旧链路通过 Chromium CDP 的 `returnByValue` 返回完整对象，CSS 属性名和值在每个节点中重复序列化、传输和解析。即使最终 WSS 补丁很小，这项工作仍会在服务器内部发生。

`capturePacked()` 在隔离执行环境中为每份采集建立独立的字符串表和样式声明表。普通样式、伪元素和顶层元素的背景样式引用这些表。引擎收到后还原相同的文档结构，继续进行安全过滤和 DOM 差异比较。相同声明在单次安全过滤中只校验一次；资源映射不会跨文档或账户复用。字典不跨采集保留，不改变网页脚本、事件转发和本地渲染协议。

这项压缩作用于 Chromium 到引擎的内部链路，不代表用户 WSS 流量按相同比例缩小。原有快照容量限制仍按还原后的文档计算，避免压缩格式绕过内存限制。

验证包括字典往返一致性、非法引用拒绝、资源映射隔离、真实 Chromium 中样式变更与伪元素恢复，以及输入、布局、资源、内存回归。`compact-capture.test.ts` 输出采集字节数和耗时；耗时受网页脚本、CPU 竞争和页面规模影响，不以固定时间作为测试通过条件。
